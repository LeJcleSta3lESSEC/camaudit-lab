# Portfolio Writeup

## Project

CamAudit Lab — Defensive local-only IoT camera audit toolkit and teaching lab.

## Problem

Home IP cameras often expose local services that users do not understand. A person on the same Wi-Fi may be able to discover cameras, fingerprint services, and sometimes access streams if RTSP/ONVIF/UPnP are misconfigured.

## Solution

A safe toolkit that automates authorized local discovery, camera candidate classification, service fingerprinting, redaction, severity classification, and report generation.

## Skills demonstrated

- networking fundamentals
- Nmap/curl/Wireshark methodology
- IoT security concepts
- Python CLI engineering
- secure subprocess handling
- evidence redaction
- vulnerability reporting discipline
- GitHub project packaging

## CV bullet

Developed CamAudit Lab, a defensive Python-based IoT camera audit framework for authorized LAN assessments, combining Nmap/curl/Wireshark workflows, service fingerprinting, evidence redaction, severity classification, and professional report generation under strict authorization guardrails.
