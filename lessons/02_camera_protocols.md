# Lesson 02 — Camera Protocols

Common camera services:

| Protocol | Common ports | Meaning |
|---|---:|---|
| HTTP/HTTPS | 80, 443, 8080, 8443 | Web/API control surface |
| RTSP | 554, 8554 | Video stream protocol |
| ONVIF | 3702 UDP, sometimes 2020 TCP | Camera discovery/control standard |
| UPnP/SSDP | 1900 UDP | Local discovery / possible router port mapping |
| mDNS | 5353 UDP | Local name advertisement |

Finding an open service is not the same as finding a vulnerability.
