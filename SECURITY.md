# Security Policy

CamAudit Lab is a defensive project for authorized local-network camera audits.

## Allowed use

- Your own network
- Family-owned network with explicit permission
- Lab devices
- Training networks where scanning is authorized

## Disallowed use

- Scanning public IPs without ownership/authorization
- Brute force
- Credential stuffing
- Default-password spraying
- Exploit execution
- Persistence
- Stealth
- Feed capture
- Camera control or settings modification

## Reporting vulnerabilities in this project

If you find a vulnerability in CamAudit itself, report it privately first. Do not publish exploit details before a fix exists.

## Evidence handling

Do not attach raw packet captures, full MAC addresses, public IPs, camera screenshots, video, serial numbers, QR codes, emails, tokens, or credentials to public issues.
